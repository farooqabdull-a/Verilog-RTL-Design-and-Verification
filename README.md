# Verilog RTL Design & Verification Portfolio

This repository contains Verilog HDL designs ranging from basic logic gates to advanced sequential circuits and arithmetic hardware modules. Each module includes testbenches, simulated waveforms, and synthesized schematics.

## 📁 Repository Structure
- **01_Combinational_Logic/** (Adders, Subtractors, MUX, Comparator, Ripple Carry)
- **02_Sequential_Logic/** (Latches, Edge-Triggered Flip-Flops)
- **03_Shift_Registers/** (SISO, SIPO, PIPO, PISO)
- **04_Counters/** (Up/Down, Ring, Johnson, Decade, Ripple Counters)
- **05_Numerical_Processing/** (Sum, Square, Factorial, Fibonacci Generator)

## 🛠️ Tools Used
- **HDL:** Verilog HDL
- **Simulator & Synthesis:** Xilinx Vivado / ModelSim / EDA Playground
